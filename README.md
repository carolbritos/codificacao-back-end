# 💻 Codificação Back-End

Bem-vindo ao repositório **Codificação Back-End**! Este espaço foi criado para organizar, documentar e armazenar estudos, exercícios e projetos práticos focados no desenvolvimento do lado do servidor (Server-Side).

---

## 🎯 Objetivos

- Compreender os conceitos fundamentais do desenvolvimento Back-End e da arquitetura web.
- Dominar a criação de APIs RESTful escaláveis, organizadas e eficientes.
- Entender a manipulação de requisições e respostas HTTP usando rotas, middlewares e controllers.
- Praticar o controle de versionamento de código e fluxo de trabalho com Git e GitHub.
- Consolidar a lógica de programação aplicada à resolução de problemas no lado do servidor.

---

## 📚 Conteúdo

O repositório está estruturado abordando os seguintes conteúdos e etapas de aprendizado:

1. **Introdução ao Back-End e Node.js**
   - Funcionamento do ecossistema Node.js e Event Loop.
   - Módulos nativos e criação de rotinas assíncronas.
   - Gerenciamento de dependências e scripts com NPM (`package.json`).

2. **Desenvolvimento de APIs com Express.js**
   - Estruturação e criação de um servidor Web HTTP.
   - Definição de rotas e verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`).
   - Leitura de parâmetros de requisição (`req.params`, `req.query` e `req.body`).
   - Implementação de **Middlewares** para validação, autenticação e logs.

3. **Arquitetura e Boas Práticas**
   - Organização e padronização da estrutura de pastas.
   - Padronização de respostas JSON e manipulação de códigos de status HTTP (Status Codes).
   - Tratamento e centralização de erros na aplicação.

## 🛠️ Tecnologias e Ferramentas

| Ferramenta | Descrição |
| :--- | :--- |
| **JavaScript** | Linguagem principal utilizada para o desenvolvimento das regras de negócio e lógica do servidor. |
| **Node.js** | Ambiente de execução JavaScript no lado do servidor (Server-side runtime). |
| **Express.js** | Framework minimalista e flexível para Node.js, utilizado para o roteamento e criação das APIs. |
| **NPM** | (*Node Package Manager*) Gerenciador de pacotes para instalação de bibliotecas e dependências do projeto. |
| **Git e GitHub** | Ferramentas utilizadas para o controle de versão, histórico de alterações e hospedagem do código fonte. |
